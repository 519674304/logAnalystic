要点： 每个 owner（flow / process / subprocess）内 order 独立从 1 编号。flow 级 order=1 固定为 role=start 开始边界，order 最大值为 role=end 结束边界；同 order 的多个 end stage 是互斥结尾。进程/子进程是 stage 的分组容器，不单独携带 order；matcher 是 stage 的叶子引用，可被多个 stage 共享。
