# 业务规则集管理需求

## 目标

规则页只负责管理已经导入的业务规则集。用户在这里导入一整份规则文件，查看规则集列表，双击打开详情，必要时编辑细节并保存，删除不再使用的规则集。

## 功能范围

- 支持导入完整业务规则集文件。
- 支持查看已导入规则集列表。
- 支持删除已导入规则集。
- 支持双击规则集条目打开详情。
- 支持在详情中编辑并保存规则集。
- 不提供主页面“新建规则集”入口。
- 不把 `log_matcher`、`stage`、`business_flow` 拆成主页面散装表单。

## 页面约定

- 主页面只保留列表、导入、删除和详情入口。
- 列表用于浏览和选择，不承担复杂编辑。
- 单击条目只做选中。
- 双击条目打开详情弹窗或详情面板。
- 规则集内部结构只在详情中展开。

## 导入范围

导入对象是一整份业务规则集，通常包含：

- `analysis_scenarios`
- `domains`
- `applications`
- `processes`
- `log_matchers`
- `stages`
- `business_flow`

这些内容作为一个整体校验和整体导入，不按单个 matcher 拆分成独立导入动作。

## 主流程

1. 用户点击导入并选择规则文件。
2. 系统校验规则集结构和引用关系。
3. 校验通过后，规则集进入列表。
4. 用户在列表中单击选择规则集。
5. 用户双击打开详情并修改细节。
6. 用户保存修改。
7. 用户删除不再需要的规则集。

## 验收标准

- 导入后可以在列表中看到规则集。
- 列表不包含复杂编辑控件。
- 双击规则集可以看到完整细节。
- 详情编辑后能保存并保留修改结果。
- 删除只影响对应规则集，不影响已导入的其他规则集。
- 规则导入失败时不应污染当前列表。
