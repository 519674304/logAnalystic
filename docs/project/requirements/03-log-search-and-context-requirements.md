# 日志搜索与上下文查看需求

## 目标

为测试人员提供一个本机可用的日志搜索工作台。用户先选择日志目录（工作区），再按关键字、正则和时间范围筛选日志，并在主页面快速查看命中内容和上下文。搜索是单个快速查询，未出结果时显示加载态。

## 功能范围

- 支持选择本地日志目录（工作区），并在同一页面完成搜索。
- 支持关键字、短语和正则搜索。
- 支持时间范围、日志级别、应用前缀、包名、tag 等结构化过滤条件。
- 支持区分大小写开关。
- 支持查看命中日志前后上下文。
- 支持将当前搜索条件（关键字/匹配模式/大小写）保存并复用；不做命名查询列表。
- 搜索是单个快速查询，同一时间只处理一个；未出结果时显示加载态，不做进度条、取消或任务 ID。
- 默认最多保留 1000 条展示命中，超出返回 `truncated` 标志，总匹配数仍持续统计。
- 结果列表滚动查看，不分页。
- 本阶段不做查询结果导出。

## 页面约定

- 日志目录与时间范围入口放在页面顶部，与搜索条件同区。
- 搜索条件区只保留「关键字/正则 + 匹配模式 + 区分大小写 + 保存条件 + 搜索」，不展示查询列表或分组筛选。
- 结果区在未出结果时显示加载态；出结果后展示命中列表（≤1000，滚动）与截断提示。
- 命中项提供「查看上下文」，点击切换为上下文视图并可返回。

## 主流程

1. 用户选择日志目录，服务创建工作区。
2. 用户输入关键字或正则，并设置匹配模式与大小写。
3. 用户发起搜索；未出结果时显示加载态。
4. 服务返回命中列表与截断状态（≤1000，滚动）。
5. 用户点击命中查看上下文。
6. 用户可将当前条件保存，后续复用。

## 验收标准

- 无 Tauri 环境下，浏览器可完成搜索主流程。
- 结果上限与截断状态明确展示，列表滚动不分页。
- 未出结果时显示加载态。
- 常规数据量下搜索与筛选保持快速响应，不影响浏览体验。
