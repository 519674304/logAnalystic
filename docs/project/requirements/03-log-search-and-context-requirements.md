# 日志搜索与上下文查看需求

## 目标

为测试人员提供一个本机可用的日志搜索工作台。用户先选择日志文件夹，再按关键字、正则、时间范围和结构化条件筛选日志，并在主页面快速查看命中内容和上下文。

## 功能范围

- 支持选择本地日志文件夹，并在同一页面完成搜索。
- 支持关键字、短语和正则搜索。
- 支持时间范围、日志级别、应用前缀、包名、tag 等结构化过滤条件。
- 支持区分大小写开关。
- 支持查看命中日志前后上下文。
- 支持隐藏左侧查询列表和搜索区域，让日志结果区域获得更多空间。
- 本阶段不做查询结果导出。

## 页面约定

- 日志文件夹入口放在页面顶部，与搜索条件同行。
- 左侧查询列表用于快速复用常用查询，支持按分组筛选。
- 查询列表支持折叠和展开。
- 查询项单击即填充当前搜索条件。
- 查询项双击打开详情弹窗。
- 页面上的新增查询入口只打开弹窗，不直接把编辑表单铺满主界面。

## 主流程

1. 用户选择日志文件夹。
2. 用户输入关键字或正则，并设置过滤条件。
3. 系统执行搜索并返回结果列表。
4. 用户点击结果查看上下文。
5. 用户可将当前条件保存为查询，后续一键复用。

## 验收标准

- 用户可以在不离开页面的情况下选择日志文件夹并开始搜索。
- 查询列表、搜索区域和结果区域在页面上保持清晰分工。
- 单击查询项会自动回填条件，双击会打开详情弹窗。
- 常用查询可直接保存并复用。
- 搜索和筛选在常规数据量下应保持快速响应，不影响浏览体验。
