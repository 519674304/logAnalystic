# 问题表：冒烟阻塞异常

个人项目快速路径：只保留冒烟阻塞异常——不可读 / 格式异常输入、破坏性替换、主流程终态失败。非冒烟的请求识别 / 时延边界问题随各自已批准阶段的职责文档处理，不在此表维护。

| ID | 发生节点 | 问题 | 当前处理方向 |
| --- | --- | --- | --- |
| ISSUE-001 | 文件读取 | 文件后缀、编码、读取失败 | 跳过该文件，报告原因，不中断其余文件 |
| ISSUE-002 | 文件读取 | 同一工作区重复文件身份 | 按文件身份去重，拒绝重复身份 |
| ISSUE-003 | 行解析 | 单行不符合固定格式 | 计入数据质量列表，不参与搜索和分析 |
| ISSUE-004 | 行解析 | 单行异常长（无界内存风险） | 设明确上限，超限报告格式问题，不无界增长 |
| ISSUE-005 | 流式读取 | 跨块边界把一行截断 | 跨块残行拼接后再解析 |
| ISSUE-006 | 搜索 | 正则语法错误或执行超时 | 保留条件，提示用户，不返回不完整结果 |
| ISSUE-007 | 搜索 | 命中数远超展示上限 | 保留前 1000 展示命中，持续统计总数，返回 `truncated` |
| ISSUE-008 | 规则包导入 | 非 ZIP、损坏、manifest 缺失或不在根目录、关键引用错误 | 拒绝整包；不创建新版本，不覆盖同版本原内容 |

## 冒烟场景

1. 选择一组合法固定格式日志目录，看到工作区摘要（文件数、总大小）。
2. 使用关键字搜索，未出结果时显示加载态，完成后看到命中与 `truncated` 状态。
3. 打开命中日志前后上下文。
4. 保存当前搜索条件，关闭后重新打开仍可恢复。
5. 导入通过本地校验的完整 ZIP 规则包，系统识别请求列表。
6. 按业务流程、时间、结束结果、是否异常筛选请求。
7. 选择一次请求，查看 A 应用处理、A 到 B 传递、B 应用处理时延。
8. 点击慢阶段，查看阶段边界日志和上下文日志。
9. 查看同类请求统计摘要，判断当前请求是否偏慢。
10. 五档规模烟测（50KB / 5MB / 30MB / 500MB / 2GB）跑主流程，峰值内存有界、结果正确。
