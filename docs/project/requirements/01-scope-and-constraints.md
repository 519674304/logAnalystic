# 范围与约束

> 本文因「Tauri → 本机 Web 服务」「整体载入内存 → 流式读取」的架构变更而修订。原「多文件整体载入 + 按时间合并 + 30MB 上限 + 批次原子导入 + P90 加载门槛」语义作废；目录工作区、逐文件流式、有界内存取代之。

## 范围内

- 本地选择日志目录，服务发现 `.log` / `.txt` 文件并形成工作区。
- UTF-8 日志文件解析。
- 固定格式单行日志解析。
- 逐文件流式读取、固定缓冲区、跨块残行拼接。
- 关键字、短语、正则、结构化字段过滤。
- 保存查询条件的本地持久化。
- 业务规则集的本地导入、编辑、导出、覆盖、备份、恢复。
- 根据规则识别请求。
- 根据规则计算请求总耗时、跨应用阶段耗时、应用内部阶段耗时、应用间传递耗时。
- 以单次请求为中心展示时延，提供统计摘要和原始日志钻取。
- 将当前筛选请求的关键日志时间戳、阶段时延及阶段统计导出为 CSV。

## 范围外

- 日志采集、拉取、上传、清洗、标准化、多格式适配。
- 自定义任意格式日志解析器。
- 自动生成业务规则。
- 错误原因知识库、自动诊断结论、修复建议。
- 查询结果和完整请求分析明细导出；时延分析 CSV 导出除外。
- 登录、权限、租户、审计、多用户协作。
- 服务器化部署、远程仓库同步。

## 数据约束

- 输入日志文件仅支持 UTF-8。
- 输入日志文件后缀仅支持 `.log` 和 `.txt`。
- 内存使用不随日志总量线性增长：固定大小缓冲区、有限结果集（默认 ≤1000 展示命中）。
- 日志时间戳按当前固定格式解析；跨年、多时区、时间校准不在首批范围。
- 解析失败行不参与搜索和时延分析，只进入数据质量列表。
- 日志、解析结果、索引、请求识别结果和时延统计只保留当前会话；关闭软件后不保留。
- 规则集、上一版本规则备份、保存查询条件保留在本地。

## 性能与容量

| 场景 | 目标 |
| --- | --- |
| 峰值内存 | 有界，不随日志总大小线性增长（由 REQ-WEB 规模烟测验证） |
| 30MB 日志 | 正常处理 |
| 1~2GB 日志（典型 ≤1GB，上限约 2GB） | 不因整体载入内存而阻塞 |
| 常用搜索、过滤、请求切换、时延视图切换 | 保持快速响应 |

不设 P90 加载耗时门槛（如 5MB≤1s、30MB≤5s）：那是边界性能调优，个人项目快速路径不投入；正确性由五档规模烟测验证（见 REQ-WEB）。

## 可靠性

- 单个文件不可读或格式异常时跳过该文件并在结果中报告原因，不中断其余文件。
- 行级解析失败不阻断读取；失败行进入数据质量列表。
- 正则执行超时时，中止该次查询，保留查询条件，并给出友好提示，不展示不完整结果。
- 规则集导入必须先完整校验；校验失败不覆盖当前规则，也不更新备份。

## 安全与运维

当前面向本机测试或开发使用，用户数量少，不做服务器化安全和运维能力。首批仅要求：

- 服务仅监听回环地址 `127.0.0.1`，不暴露到局域网或公网。
- 不引入登录和权限。
- 不主动上传日志或规则数据。
- 不保留会话日志数据。
- 对导入失败、解析失败、规则校验失败、正则超时提供可理解提示。
