# 保存查询需求

> 已废止（2026-08-25）：日志搜索页不再提供命名查询列表与查询管理，改为「保存查询条件」（关键字/匹配模式/大小写），见 REQ-SEARCH。

## 目标

保存查询是测试人员的本地个人配置，用来复用常用搜索条件。它不参与日志解析和时延计算，只负责把可复用的搜索条件保存、调用和管理起来。

## 功能范围

- 支持保存当前搜索条件。
- 保存查询包含名称、描述、分组、标签、关键字或正则、大小写选项以及结构化过滤条件。
- 支持查看、调用、编辑和删除保存查询。
- 支持在查询列表中按分组筛选。
- 保存查询的新增与编辑通过弹窗完成。
- 保存查询不受业务规则集导入、覆盖和恢复影响。

## 页面交互

- 查询列表单击后，将该查询的条件回填到当前搜索区域。
- 查询列表双击后，弹出详情窗口查看完整配置。
- 新建查询入口打开新建弹窗，不直接进入页面编辑态。
- 当前页面不保留草稿区，避免和搜索操作混在一起。

## 主流程

1. 用户在搜索页调整搜索条件。
2. 用户点击保存，将当前条件转成查询配置。
3. 用户后续在查询列表中单击即可复用。
4. 用户双击可以查看详情并再次编辑。
5. 用户可以删除不再需要的查询。

## 验收标准

- 查询保存后可以立即在列表中看到。
- 重新打开软件后，本地保存的查询仍然存在。
- 调用保存查询后，搜索条件能够完整恢复。
- 导入或恢复规则集不会修改保存查询。
